# AutoTH

สลับแป้นพิมพ์ไทย/อังกฤษให้อัตโนมัติบน macOS ดูจากคำที่คุณกำลังพิมพ์ ไม่ต้องกดเปลี่ยนภาษาเองอีก

*Auto-switches your Mac keyboard between Thai and English based on what you're typing.*

พิมพ์ `l;ylfu` บนแป้นอังกฤษ ก็ได้ "สวัสดี" พิมพ์ "้ำสสน" บนแป้นไทย ก็ได้ `hello` แป้นสลับไปภาษาที่ถูกให้ด้วย คำต่อไปจึงพิมพ์ต่อได้เลย

## ทำอะไรได้บ้าง

- **สลับภาษาระหว่างพิมพ์** ถ้าเห็นชัดว่าพิมพ์ผิดแป้น สลับได้ตั้งแต่ตัวที่ 3 ถ้ายังไม่ชัด รอตัดสินตอนกด space
- **แก้คำไทยพิมพ์ผิด** ตอนจบคำ กดซ้ำ (`ทที่ไหน` → `ที่ไหน`) และกดวรรณยุกต์ก่อนสระ (`ท่ี` → `ที่`)
- **555 เป็นตัวเลข** บนแป้นไทย ปุ่ม 5 คือ ถ พอกดครบ 3 ครั้งติดกันจะกลายเป็น 555 ตัวเลขอื่น เช่น ปี หรือเบอร์โทร ก็ไม่ถูกแปลง
- **ย้อนกลับได้** กด `⌃Space` (ตั้งเองได้) หลังแอปเปลี่ยนคำ แล้วคำนั้นจะกลับเป็นแบบที่คุณพิมพ์ พร้อมกลับไปแป้นเดิม ถ้าไม่มีอะไรให้ย้อน `⌃Space` ก็สลับภาษาตามปกติของ macOS
- **เปิดเองตอนเปิดเครื่อง** เลือกได้จากเมนู

## ติดตั้ง

ต้องใช้ macOS 13 ขึ้นไป และเปิดแป้นทั้งอังกฤษ (ABC หรือ U.S.) และไทยไว้ใน System Settings › Keyboard › Input Sources

1. โหลด `AutoTH.zip` จากหน้า [Releases](https://github.com/PongsakornNaklang/AutoTH/releases/latest) แล้วแตกไฟล์ ลาก `AutoTH.app` ไปไว้ใน Applications
2. แอปยังไม่ได้ผ่าน notarize ของ Apple ครั้งแรกให้คลิกขวาที่แอปแล้วเลือก **Open** หรือรันคำสั่งนี้ก่อน

   ```bash
   xattr -dr com.apple.quarantine /Applications/AutoTH.app
   ```

3. พอเปิดแอป ไอคอน `ก⚠A` จะขึ้นที่แถบเมนู และหน้าต่าง Privacy & Security › Accessibility จะเปิดให้เอง เปิดสวิตช์ AutoTH ภายใน 2 วินาที ไอคอนจะเปลี่ยนเป็น `ก⇄A` แปลว่าพร้อมใช้

> ถ้าเปิดสวิตช์แล้วไอคอนยังเป็น `ก⚠A` ให้ลบ AutoTH ออกจากรายการด้วยปุ่ม − แล้วเพิ่มใหม่ด้วยปุ่ม + เพราะ macOS จะไม่รับสิทธิ์เดิมทุกครั้งที่ตัวแอปเปลี่ยน เช่น อัปเดตเวอร์ชัน หรือ build เอง

## ใช้งาน

| ไอคอน | ความหมาย |
|---|---|
| `ก⇄A` | ทำงานอยู่ |
| `ก⚠A` | ยังไม่ได้สิทธิ์ Accessibility |
| `ก·A` | ปิดไว้ชั่วคราว |

เมนูของไอคอนมีปุ่มเปิด/ปิดการสลับอัตโนมัติ, **Open at Login**, **Settings…** (ตั้งปุ่มลัดสำหรับย้อนกลับ) และปุ่มเปิดหน้าต่าง Accessibility

ปุ่มลัดย้อนกลับใช้ได้สองช่วง คือตลอดคำที่แอปเพิ่งสลับภาษาให้ระหว่างพิมพ์ กับทันทีหลังแอปแปลงหรือแก้คำตอนกด space ถ้ากด Enter หรือคลิกเมาส์ไปแล้ว จะย้อนไม่ได้

## ทำงานยังไง

AutoTH จำว่าคำปัจจุบันกดปุ่มไหนไปบ้าง แล้วอ่านปุ่มชุดเดียวกันผ่านทั้งแป้นอังกฤษและแป้นไทยที่เปิดอยู่ในเครื่อง

- ฝั่งอังกฤษ ใช้ spell checker ของ macOS
- ฝั่งไทย macOS ไม่มีตัวตรวจคำไทยให้ จึงใช้สองชั้น ชั้นแรกเป็นกฎการสะกด เช่น วรรณยุกต์ต้องตามหลังพยัญชนะ หรือ เ แ โ ใ ไ ต้องมีพยัญชนะตาม ชั้นที่สองเทียบกับคลังคำไทยราว 26,000 คำ ต้องเป็นคำในคลังอย่างน้อย 90% ถึงจะนับเป็นไทย

ถ้าอีกภาษาเข้าท่ากว่า แอปจะลบคำที่พิมพ์ไป สลับแป้น แล้วพิมพ์คำใหม่ให้ ทั้งหมดทำในเครื่อง ไม่มีอะไรส่งออกไปนอกเครื่อง

## ข้อจำกัด

- ตัดสินทีละคำ ไม่ดูบริบทจากคำก่อนหน้า
- คำไทยบางคำบนแป้นอังกฤษบังเอิญเป็นคำอังกฤษจริง เช่น ทำไม = `mew,` และ ทำ = `me` พวกนี้แอปจะไม่แปลงให้
- คำทับศัพท์ที่ไม่มีในคลัง เช่น ลิสต์ อาจไม่ถูกแปลง
- ทำงานทุกแอปเหมือนกัน ยังตั้งให้ข้ามบางแอปไม่ได้

## Build เอง

ต้องมี Xcode หรือ Command Line Tools

```bash
./build.sh && open AutoTH.app
```

`build.sh` จะ build แอป universal (Apple silicon + Intel) แล้วรันชุดทดสอบของตัวตัดสินใจให้ด้วย ถ้าอยากรันชุดทดสอบอย่างเดียว ใช้ `AutoTH.app/Contents/MacOS/AutoTH --selftest`

โค้ดทั้งหมดอยู่ใน `main.swift` ไฟล์เดียว
